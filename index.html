Ingat konsep kunci

1

Garis batas diperoleh dengan mengganti tanda pertidaksamaan menjadi tanda sama dengan.

2

Titik uji seperti (0, 0) membantu menentukan sisi garis yang memenuhi pertidaksamaan.

3

Daerah solusi adalah irisan semua daerah yang memenuhi setiap pertidaksamaan secara bersamaan.

4

Garis penuh untuk ≤ atau ≥ karena batas termasuk solusi. Garis putus-putus untuk < atau > karena batas tidak termasuk.

Produksi paket belajar

Sebuah tim menyiapkan dua jenis paket, yaitu Paket A dan Paket B. Misalkan x adalah banyak Paket A dan y adalah banyak Paket B. Waktu persiapan membatasi jumlah paket dengan syarat x + 2y ≤ 12, sedangkan persediaan bahan membatasi 2x + y ≤ 12. Jumlah paket tidak mungkin negatif.

x + 2y ≤ 12
2x + y ≤ 12
x ≥ 0 dan y ≥ 0

FOKUS PENALARAN

Buktikan, jangan hanya menebak

Gunakan urutan berpikir berikut ketika memeriksa suatu titik.

①

Substitusikan

Masukkan nilai x dan y dari titik yang diuji ke ruas kiri setiap pertidaksamaan.

②

Bandingkan

Bandingkan hasil perhitungan dengan konstanta di ruas kanan. Perhatikan tanda ≤, ≥, <, atau >.

③

Periksa semua syarat

Satu titik termasuk daerah solusi sistem hanya jika memenuhi seluruh pertidaksamaan secara bersamaan.

Latihan penalaran mandiri

Periksa titik (3, 3) untuk sistem berikut:

x + 2y ≤ 12
2x + y ≤ 12
x ≥ 0 dan y ≥ 0
